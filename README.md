# ITS·교통·재난안전 기술수요조사

교통·도로·재난안전 현장의 기술수요를 취합하기 위한 정적 HTML/CSS/JavaScript 기반 설문 페이지입니다. 레퍼런스 설문처럼 제출 기관 정보와 복수 입력 가능한 수요 항목을 제공하며, Supabase 연결 전에는 브라우저 저장소와 CSV 다운로드로 테스트할 수 있습니다.

## 설문 초안 구성

- 제출 기관 정보: 기관명, 부서명, 작성자, 직위/직책, 연락처, 이메일
- 조사 안내: 붙임자료, 담당/조사, 문의처, 회신처
- 작성 참고 가이드북: 분야 1~4 추진현황, 도입사례, 기대효과를 스와이프 카드로 확인
- 가이드 반영: 각 분야의 `이 분야 내용 반영`을 체크하면 첫 번째 기술수요 초안에 해당 분야 예시가 자동 입력
- 기술수요 개요: 기술수요명, 수요 유형, 분야, 추진 시급성, 적용 대상/현장, 검토 단계
- 상세 문항: 추진 배경, 현장 문제 및 애로사항, 필요 기술/서비스 내용, 보유 데이터, 기대효과 및 활용계획
- 기타 입력: 참고자료/링크, 기타 의견

## 실행

```bash
npm run dev
```

## Supabase 저장 설정

`technology_demand_surveys` 테이블을 만든 뒤 `index.html` 또는 배포 템플릿에서 다음 전역 변수를 설정합니다.

```bash
window.SUPABASE_URL = "...";
window.SUPABASE_ANON_KEY = "...";
```

제출 payload는 응답 ID, 제출 시각, 기관 정보, `demands` 배열, 원본 Google Sheet 링크를 포함합니다.
